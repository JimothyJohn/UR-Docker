PERCEPTRONICS

01WINDOWSNO EXPERIENCE NEEDED

Set it up on Windows

Follow the five steps in order. You will not type any commands and you do not need to know what "git" or "Python" are — you click a download button and double-click two files. If anything on your screen does not match what a step says, stop and go to Troubleshooting.

  • A computerWindows 10 or Windows 11.
  • InternetConnected for the whole setup.
  • TimeAbout 15 minutes, once.
  • Robot and cameraNot needed. Practice mode works with neither.

How to read this page: a green block is something you click, a key is a key on your keyboard, and amber text is the name of a file or folder.

  1. Download it

    Download Perceptronics (ZIP)

    1. Click the button above, once.
    2. Wait until your browser says the download is finished (a small box at the top right or the bottom of the browser window). If it asks Keep or Save, click it.
    You should now haveA file named perceptronics-main in your Downloads folder. Its icon is a folder with a zipper on it.

  2. Unzip it

    The download is a "ZIP": many files packed into one. It has to be unpacked before anything in it works. This is the step people skip.

    1. Hold the Windows key (the one with the four squares, bottom left of the keyboard) and press E. A window called File Explorer opens.
    2. On the left side of that window, click Downloads.
    3. Find perceptronics-main. Click it once with the right mouse button. A menu appears.
    4. In the menu, click Extract All…
    5. A box appears. Change nothing. Click Extract.
    6. A new window opens showing a folder also named perceptronics-main. Double-click it to open it.

  4. Start it

    This is the only step you repeat. Every time you want to use Perceptronics, do this.

    1. In the same folder, double-click Windows-Start. (If the blue warning appears again, do the same as before: More info, then Run anyway.)
    2. A black window asks for a cell name. Type nothing. Just press Enter. That starts practice mode.
    3. After a few seconds your web browser opens by itself.
    You should now seeA dark page with a green 3-D picture of a table with blocks on it. Hold the left mouse button on the picture and move the mouse to look around.
    Keep the black window openThe black window is the program. The page in your browser stops working the moment that window is closed. You can shrink it with the – button at its top right.

    Messages on the page that the robot is unreachable or not connected are correct in practice mode: there is no robot.

  5. Stop it

    1. Close the browser tab.
    2. Click the black window, then click the X at its top right.

    To use it again later: open Downloads, open perceptronics-main, and do step 4. You never repeat steps 1 to 3 on this computer.

With a real robot or camera

Get three things from the person who installed your robot before you start: the cell name to type in step 4 instead of pressing Enter alone (for example ur3), confirmation that this computer is on the robot's network, and a check that the robot's tablet is switched to Remote. Plug the camera into a blue USB socket using the cable that came with it, then run step 3 again and answer Y.

02TROUBLESHOOTINGFOLLOW THE ARROWS

Something went wrong

Start at the top of the chart. Answer each question. Yes takes you down to the next question. No takes you right: find the line that matches what you see, and click the box beside it for the full fix.

  • A question
  • What you see
  • What to do (click it)

AThe download

  1. Click the download button in step 1 again and watch the top right and the bottom of the browser window. If it asks Keep or Save, click it.
  2. To find the file: hold Windows, press E, click Downloads on the left. The newest file is at the top.
  3. If you downloaded more than once you will see perceptronics-main (1) and so on. Any of them works; use the newest.

On a work computer the download can be blocked outright. If the button does nothing at all, that is a question for your IT department.

BUnzipping

  1. If the black window said "still inside the ZIP", you double-clicked the ZIP instead of unpacking it. Close everything.
  2. In Downloads, right-click the perceptronics-main with the zipper icon and click Extract All…, then Extract.
  3. No Extract All… in the menu? Click Show more options at the bottom of the menu first. Or click the file once and use Extract all in the bar at the top of the window.
  4. If you open the new folder and see only one folder inside it, also called perceptronics-main, open that one too. The two files are one level deeper.

Never move Windows-Setup or Windows-Start out of their folder (to the Desktop, say). They only work next to the other files.

CWindows won't run the file

  1. "Windows protected your PC" (blue): click More info, then Run anyway. There is no Run button until you click More info.
  2. "The publisher could not be verified": click Run.
  3. It opened as a page of text in Notepad: close Notepad. Right-click the file and click Open — not Edit.
  4. "This app has been blocked by your system administrator": your company does not allow it on this computer. Only IT can change that.

DSetup can't reach the internet

Red text containing Unable to connect, could not be resolved or timed out means a download failed.

  1. Open any website in your browser to check the internet works.
  2. If you are on a company network or VPN, try a home network or a phone hotspot — company networks often block these downloads.
  3. Double-click Windows-Setup again. It continues where it stopped.

EPermission and passwords

  1. If you clicked No on "Do you want to allow this app to make changes?", run Windows-Setup again and click Yes.
  2. If Windows asks for an administrator password you do not have: run Windows-Setup again and press N at the camera question. Practice mode needs no permission. For a real camera, ask IT to install the Intel RealSense SDK 2.0.

FThe camera installer

  1. The setup pauses while a separate installer window is open. It can hide behind other windows: look for a new icon flashing on the taskbar at the bottom of the screen.
  2. Click Next, accept the agreement, Install, Finish. Do not change where it installs.
  3. A yellow warning mentioning realsense2.dll means it was installed somewhere unusual. Uninstall Intel RealSense SDK 2.0 from Windows Settings → Apps, then run Windows-Setup again without changing the install location.

GSetup did not finish, no clear reason

  1. Restart the computer.
  2. Double-click Windows-Setup again. It is safe to run as many times as you like.
  3. Still not finished? Go to Getting help.

HStart says setup is missing

  1. "Setup has not been run yet": do step 3, then come back.
  2. The same message although setup said SETUP FINISHED: Windows has not noticed the new software yet. Restart the computer and double-click Windows-Start again.
  3. Still the same after a restart: run Windows-Setup once more.

IThe page doesn't appear

  1. Check the black window is still open. If it is gone, start again and leave it open.
  2. Open your browser yourself (Edge or Chrome). Click the long bar at the very top where website addresses go, type localhost:7621 and press Enter.
  3. "Can't reach this page" or "refused to connect" with the black window open: wait ten seconds and press F5 to reload.

JIt is already running

"Only one usage of each socket address" or "address already in use" means Perceptronics was started twice.

  1. Close every black window.
  2. Double-click Windows-Start once.
  3. If it still says so, restart the computer and start once.

K"Robot unreachable" in practice mode

Nothing is wrong. Practice mode has a pretend camera and no robot, so the page reports that it cannot find one. Everything you can do with the picture still works.

L"Unknown cell"

  1. The cell name was mistyped. Close the black window and start again.
  2. Press Enter alone for practice mode, or type the name exactly as your robot installer gave it to you — small letters, no spaces.
  3. If you typed a real cell name but still see the practice picture of blocks, you pressed Enter before typing. Start again.

MThe real camera shows nothing

  1. "librealsense2 not found": the camera software is missing. Run Windows-Setup again and press Y.
  2. Unplug the camera. Plug it into a blue USB socket on the computer itself — not a hub, not the keyboard — using the cable that came with the camera.
  3. Close every other program that uses a camera: Intel RealSense Viewer, Teams, Zoom, the Windows Camera app. Only one program can use the camera at a time.
  4. Close the black window and double-click Windows-Start again.

NThe real robot is unreachable

  1. Check the network cable between this computer and the robot (or its switch) is plugged in at both ends and the little lights beside the socket are on.
  2. Check the robot is powered on and its tablet shows its normal screen.
  3. Still unreachable: the robot's address in the cell settings is the installer's job. Tell them the exact words on screen.

OThe robot doesn't move

  1. On the robot's tablet, look at the top right corner. If it says Local, tap it and choose Remote. This can only be done at the robot.
  2. "OUT OF REACH" on the page: the object is too far away for the arm. Move it closer to the robot's base and try again.

PGetting help

Do not close the black window. Take a photo of it with your phone, showing the last lines of text, and send it to the person who gave you this page — or open an issue and attach the photo. Say which step number you were on.

03DEVELOPERSQUICK START

Start the simulator

You need Docker and Python ≥ 3.10.

> git clone https://github.com/JimothyJohn/perceptronics && cd perceptronics
> docker compose up -d       # pendant: http://localhost:6080/vnc.html
> python3 -m urctl bring-up      # power on + release brakes
> python3 -m urctl state

On Apple Silicon, run the PolyScope X sim instead: HOST_ARCH=arm64 make simx-up.

04USE IT

Move it

> python3 -m urctl move-joints 0 -1.57 0 -1.57 0 0      # joint move (radians)
> python3 -m urctl move-tcp 0 0.05 0 0 0 0 --relative   # tool +50 mm in base Y
> python3 -m urctl --host 10.0.0.5 state                # a real robot
> python3 -m urctl.mcp_server --host 10.0.0.5                  # the same commands as MCP tools

Every move is checked by a safety envelope before it is sent and is written to an audit log. On a real robot, set the pendant to Remote first.

05CAMERAOPTIONAL

Click to pick

A RealSense D435 on the tool flange turns a click on the camera image into a robot move.

> python3 -m perceptronics gui --fake    # no camera needed
