PERCEPTRONICS

Drive a Universal Robots arm from your laptop. A PolyScope simulator in Docker, and urctl — one Python tool that drives the simulator and a real robot the same way.

Get started GitHub
RANGE SCAN—SYNTHETIC
01QUICK START

Start the simulator

You need Docker and Python ≥ 3.10.

> git clone https://github.com/Olympus-Controls/UR-utils && cd UR-utils
> docker compose up -d       # pendant: http://localhost:6080/vnc.html
> uv sync
> uv run urctl bring-up      # power on + release brakes
> uv run urctl state

On Apple Silicon, run the PolyScope X sim instead: HOST_ARCH=arm64 make simx-up.

02USE IT

Move it

> urctl move-joints 0 -1.57 0 -1.57 0 0      # joint move (radians)
> urctl move-tcp 0 0.05 0 0 0 0 --relative   # tool +50 mm in base Y
> urctl --host 10.0.0.5 state                # a real robot
> urctl-mcp --host 10.0.0.5                  # the same commands as MCP tools

Every move is checked by a safety envelope before it is sent and is written to an audit log. On a real robot, set the pendant to Remote first.

03CAMERAOPTIONAL

Click to pick

A RealSense D435 on the tool flange turns a click on the camera image into a robot move.

> uv run perceptronics --fake gui    # no camera needed
