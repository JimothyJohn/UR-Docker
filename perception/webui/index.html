    Robot

    –
    Segment an object with depth, then Locate.
    Locate reads the live flange pose and maps the segment's camera point into the base frame through the hand-eye transform (bracket nominal unless PERCEPTION_T_FLANGE_CAMERA is set). Move sends one safety-validated movel to the approach pose: standoff short of the point along the camera ray, tool orientation unchanged. from picks what the standoff is measured to — the active TCP, or the tool flange (use flange when the controller's active TCP isn't the physical tool). The cell file sets the defaults (PERCEPTION_STANDOFF_M, PERCEPTION_APPROACH_REFERENCE). Approach is the test loop: click an object (depth region-growing, no model), then Approach — the arm goes over it, down to the standoff, holds a second, comes back up and returns to where the picture was taken, all as one program. Move the object, click, Approach again.
    Calibrate hand-eye –
    1. Freedrive the tool tip onto a mark → Record mark. 2. From 4–6 varied poses (rotate + tilt the wrist), click the mark in the colour view → Add view. 3. Solve, check the residuals, Apply.
